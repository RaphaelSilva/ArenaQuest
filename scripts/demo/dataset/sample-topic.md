## Paragraphs and line breaks

A paragraph is one or more lines of text separated by a blank line.
Consecutive lines like these two are joined into the same paragraph.

This line ends with two trailing spaces,  
so the next one starts on a new line (a hard line break).

### Emphasis

Text can be **bold**, *italic*, or ***bold and italic*** at once.
The underscore forms work too: __bold__, _italic_ and ___both___.

## Blockquotes

> A blockquote sets a passage apart.
>
> It can span several paragraphs.
>
>> And it can nest another quote inside it.

## Lists

  - What to review next time

## Code

Use `inline code` for short snippets such as a command name.

```js
function greet(name) {
  return `Hello, ${name}!`;
}
```
